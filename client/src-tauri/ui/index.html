NewAgentUniverse desktop shell

Every button below calls a Rust command in src-tauri/src/lib.rs, which performs a real HTTP request against nau-daemon. Unlike upstream's shell — 36 lines of Rust exposing two commands that no frontend ever invoked — nothing here returns a constant.

Unbuilt shell. This Tauri crate has never been compiled (see client/README.md §7 and client/platforms/). The verified client is the browser UI in client/index.html.
