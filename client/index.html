Every action on this page is a real HTTP call to a running nau-daemon, signed in this tab with crypto.subtle Ed25519. There is no simulation and no npm dependency: client/lib/nau.mjs is loaded directly as an ES module.

1 · Identity

A 32-byte seed is imported as PKCS#8 DER (302e020100300506032b657004220420 + seed); the raw public key is the last 32 bytes of the SPKI export, and the DID is did:nau: + the first 8 bytes of SHA-256(raw key) in lowercase hex. The daemon verifies the signature and the DID↔key binding itself — this page cannot mint an identity the daemon will accept without the matching private key.

5 · Conservation and audit, side by side

        

          GET /conservation reads the O(1) counters; GET /audit
          independently recomputes the same totals from the account table. They must agree, and
          discrepancy must be exactly 0. This is the project's core
          invariant and the reason Money is an integer.
