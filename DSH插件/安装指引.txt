```
package/lib/index.js         624 B   ← 刻意留空的入口（见下）
package/lib/tools.js      10,124 B   ← 真正的 Cordis 插件（apply + inject）
```

**装载路径一处值得说明**：`lib/index.js` 是**故意留空**的。文件头注释写明了原因——profile 挂载的是 `tools` 子路径（由 `cordis.patch.yml` 的 `insert` **显式指定**），这样**读 profile 就知道包的哪个模块成为插件**，不必依赖「根导出即插件」的约定。空文件存在只为避免 manifest 指向不存在的文件时报解析错误。

**它提供 5 个只读工具**（实测注册数 = 5，与 README 一致）：

```
nau_version    nau_inspect    nau_conformance    nau_amount    nau_node_status
```

## 三、安装代码

### 1. 标准方式（harness 自带命令）

语法是**从 harness 自己的文本里查实的**，不是我记忆里的：

```sh
dsh plugin --profile <profile-name> add @twinsearth/nau-dsh-plugin
```

带版本锁定：

```sh
dsh plugin --profile <profile-name> add @twinsearth/nau-dsh-plugin@3.4.5
```

harness 明确支持**四种来源**：包名（可带版本）、Git 地址、tarball、本地绝对路径。

### 2. 手工方式（我实测跑通的就是这条）

`dsh plugin add` 本质是转发给 pnpm，所以等价操作是两步：

```sh
# 步骤 1：在 profile 目录安装
cd ~/.dsh/profiles/<profile-name>
pnpm add @twinsearth/nau-dsh-plugin@3.4.5

# 步骤 2：把它加进 profile 的 bundle 列表
#   编辑同目录的 package.json：
#   "dsh": { "profile": { "bundles": [
#       "@deepseek-ai/dsh-base",
#       "@deepseek-ai/dsh-web-app",
#       "@twinsearth/nau-dsh-plugin"     ← 加这一行
#   ] } }
```

**实测结果**（全新 profile，从 npm 装）：

```
+ @twinsearth/nau-dsh-plugin 3.4.5        22 packages
Added 1 entry to minimumReleaseAgeExclude in pnpm-workspace.yaml
Done in 4s using pnpm v11.7.0
```

最后那行是 harness 的**供应链策略**（`minimumReleaseAge` 拦截新发布的包），安装器会自动加豁免条目——**这是设计行为，不是故障**。

### 3. 离线 / tarball 安装

```sh
# 下载
curl -LO https://github.com/TwinsEarth/NewAgentUniverseByDeepSeek/releases/download/v3.4.5/twinsearth-nau-dsh-plugin-3.4.5.tgz

# 校验（应得到 BE08A2B9…620F）
sha256sum twinsearth-nau-dsh-plugin-3.4.5.tgz

# 安装
dsh plugin --profile <profile-name> add /abs/path/to/twinsearth-nau-dsh-plugin-3.4.5.tgz
```

### 4. 从 GitHub Packages 安装（需凭据）

GitHub Packages **即使公开包也要求认证**。先在 `~/.npmrc` 写入：

```
@twinsearth:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=<你的-token>
```

token 需有 `read:packages`。然后：

```sh
dsh plugin --profile <profile-name> add @twinsearth/nau-dsh-plugin@3.4.5
```

### 5. 验证安装成功

装完不该只看「有没有报错」。因为**装得上不代表加载得起来**——这个包当初就踩过这个坑（依赖写成 peer-only，装完 import 失败）：

```sh
cd ~/.dsh/profiles/<profile-name>
node -e "
const p = require('@twinsearth/nau-dsh-plugin/tools');
console.log('inject:', p.inject, '| apply:', typeof p.apply);
const r = []; p.apply({tools:{register:t=>r.push(t)}}, {bin:'nau'});
console.log('registered tools:', r.length);
"
```

期望输出：

```
inject: [ 'tools' ] | apply: function
registered tools: 5
```

**注意入口是 `/tools` 而不是包根**——包根 `lib/index.js` 是刻意留空的（原因见上）。
