## 不得回退的基线

以下八项经代码文本核实且具备真实生产调用点（引自自审 §6），是后续补丁**不得回退**的基线：

1. 资金守恒与精确整数：`Money(i64)`；结算全量重扫后精确相等（无 epsilon、无 f64）；三条资金路径封死铸币；金额入口拒绝 JSON 浮点。
2. 证据闸门 fail-closed 与重启完整性：需证据的任务必须存在可信信封；`verification_policy`/`winner_price`/信封/信誉/质押持久化并在重启后存活。
3. 独立审计有真实调用点：被 REST、MCP 与结算前重放实际调用，按重放集与当前集并集比对。
4. 服务端裁定状态与罚则：状态变更仅经唯一转移表，终态无入边；罚则由服务端规则决定而非请求体。
5. 传输鉴权 fail-closed：REST 写路由与 MCP 写/动钱工具未配凭据即拒绝；三种 MCP 传输共用同一参数校验入口。
6. 插件通信不可冒充：PMB 七检查在唯一 dispatch 点；每插件随机 HMAC、常量时间比较；outbox 由宿主代投。
7. 沙箱「做不到就拒绝」：未实现隔离的后端零构造或类型化拒绝；process 后端要求书面豁免、缺豁免返回 422。
8. 跨语言一致性与测试纪律：金额向量两端逐账户断言；签名向量由独立实现生成并逐字节命中；12 个版本声明点全绿；全仓 0 个 `#[ignore]`。
